## Current Technical Work

### Schema Gorilla

[Schema Gorilla](https://sydneybusinessweb.com.au/schema-gorilla-business-identity-analysis-for-ai/) is a whole-site entity and structured-data analysis system developed by Sydney Business Web.

It examines whether organisations, people, services, identifiers, relationships, visible content and structured data combine to form a coherent machine-readable representation of a business.

The public repository documents the architecture and analysis methodology. Production algorithms and implementation remain proprietary.

### AI Observatory

[AI Observatory](https://sydneybusinessweb.com.au/ai-observatory/) is a server-side retrieval-monitoring system developed by Sydney Business Web.

It provides observable evidence of recognised AI and search crawler activity, including which website resources are requested, whether qualifying retrievals succeed, and how machine access changes over time.

The system deliberately distinguishes **retrieval evidence** from claims about AI understanding, citation, recommendation or model training.

### AI Identity Diagnostic

[AI Identity Diagnostic](https://sydneybusinessweb.com.au/ai-visibility-analysis/) is a structured assessment of a business's machine-readable identity, including entity resolution, completeness and external corroboration.

It builds on structural analysis to identify where a business identity is unclear or insufficiently supported. It does not, by itself, establish AI search inclusion or recommendations.

**Zenodo record:**  
https://zenodo.org/records/22119042

### AI Baby Gorilla

[AI Baby Gorilla](https://sydneybusinessweb.com.au/ai-baby-gorilla/) is a free, single-page structured-data connectivity checker developed by Sydney Business Web.

It reports whether key entity relationships are connected, partly connected or fragmented. An access-controlled API also supports use in automated agent workflows; the public tool and documentation do not constitute an open-source release of the production service.
